# Qt6DrawAll

Qt6DrawAll is a small desktop image tool built with **Qt 6.5.3** and **C++**.  
It is designed to provide a lightweight environment for image viewing, drawing, and annotation. The project focuses on simple interaction, basic editing features, and a clear Qt-based user interface.

## Features

- Open and display image files
- Basic drawing and annotation support
- Simple image editing workflow
- Save modified images
- Desktop user interface based on Qt Widgets

## Technology Stack

- **C++**
- **Qt 6.5.3**
- **Qt Widgets**

## Project Purpose

This project was created as a small practice-oriented desktop application based on Qt 6. It demonstrates how to build an image tool with drawing-related functionality and interactive UI components.

## Getting Started

### Requirements

- Qt 6.5.3
- A C++ compiler compatible with Qt 6
- CMake or Qt Creator

### Build and Run

1. Clone the repository
2. Open the project in Qt Creator or configure it with CMake
3. Build the project
4. Run the application

## Usage

After launching the application, users can load an image, perform drawing or annotation operations, and save the result through the graphical interface.
